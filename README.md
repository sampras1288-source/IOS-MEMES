# Мемы — версия для iPhone (веб-приложение)

1. Создайте на github.com НОВЫЙ ПУБЛИЧНЫЙ репозиторий (Public) и загрузите в него все файлы из этой папки (папку memes тоже).
2. Settings → Pages → Source: Deploy from a branch → Branch: main, папка /(root) → Save.
3. Через 1–2 минуты вверху страницы Pages появится адрес вида https://ВАШ-НИК.github.io/ИМЯ-РЕПО/
4. Откройте адрес в Safari на iPhone → кнопка «Поделиться» → «На экран „Домой“».
5. Запускайте приложение с иконки на экране «Домой».

Свои мемы добавляйте прямо в приложении кнопкой «Добавить мем» — они хранятся на телефоне.
Вшитые мемы: файлы в папке memes + строки в memes/manifest.json. После изменения файлов в репозитории
откройте приложение два раза: первый раз оно подтянет обновление, второй раз покажет.
